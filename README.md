# Work Time Tracker / Учёт рабочего времени

Небольшое веб-приложение для учёта рабочего времени. Оно позволяет добавить сотрудников, запустить и остановить таймер с описанием задачи, посмотреть записи и общее время за выбранный период. Интерфейс доступен на русском и английском. Авторизации нет; для демонстрации используйте только вымышленные данные.

## Запуск в Windows

Нужен Python 3. Дважды щёлкните [start.bat](start.bat). При первом запуске он создаст `.venv`, установит зависимости из `requirements.txt`, создаст локальную базу SQLite и откроет приложение по адресу <http://127.0.0.1:5000/>. Для остановки закройте окно сервера или нажмите `Ctrl+C`. Файл базы и виртуальное окружение не попадают в Git.

Из терминала PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py
```

Проверки:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

## Как пользоваться

1. Добавьте вымышленного сотрудника.
2. Выберите его, введите задачу и запустите таймер.
3. Остановите таймер кнопкой «Стоп»; пока он работает, время продолжает входить в отчёт.
4. Укажите даты начала и конца и откройте отчёт. Обе даты включены по местному времени браузера. Запись, пересекающая границу периода, учитывается только в пределах выбранных дат.
5. Переключите RU/EN в заголовке. Выбор языка сохраняется после обновления страницы.

## Устройство проекта

- `app/db.py` — схема SQLite: сотрудники, записи времени и уникальный индекс, разрешающий не более одного активного таймера на сотрудника.
- `app/service.py` — проверка ввода, правила запуска и остановки, расчёт пересечения записей с отчётным периодом.
- `app/routes.py` — JSON API и страница приложения.
- `app/templates/` и `app/static/` — интерфейс без клиентского фреймворка.
- `tests/` — сценарии API, включая повторный запуск, пустой отчёт, пересечение границ и сохранение после перезапуска.

Время в базе хранится в UTC. Интерфейс переводит выбранные местные даты в полуоткрытый UTC-интервал `[from, to)`. Для активной записи сервер делает один снимок текущего времени на отчёт и использует его при расчёте.

## ИИ в разработке

Использовался OpenAI Codex на модели семейства GPT-6 с скиллами и профилями агентов ECC, а также `ui-ux-pro-max` для рекомендаций по интерфейсу. Реальные запросы и результаты записаны в [журнале ИИ](docs/AI_WORK_LOG.md). Примеры запросов:

- «Предложи структуру Flask/SQLite, контракты API, правила атомарного запуска и тесты граничных случаев. Файлы не меняй.»
- «Реализуй Flask API, SQLite и тесты: повторный запуск, пустой отчёт, границы периода, сохранение после перезапуска.»
- «Реализуй RU/EN интерфейс, фильтр дат, активный таймер и понятные ошибки по заданному JSON-контракту.»

Сгенерированный код проверялся тестами и ручным прогоном. Пример найденной ошибки: обработчик ожидал JSON-объект, и при передаче массива возникала серверная ошибка. Обработчик был исправлен так, чтобы возвращать ошибку валидации `400`; добавлен отдельный тест.

## Graphify и история изменений

После появления исходных файлов построен граф проекта. При дальнейшем изучении сначала используйте `graphify query` для поиска нужных узлов и связей, затем открывайте найденные исходные файлы. После изменений обновляйте граф через `graphify update .`. Переносимые результаты находятся в `graphify-out/graph.json` и `graphify-out/GRAPH_REPORT.md`; на новом клоне граф можно перестроить командой `graphify . --code-only`, затем `graphify cluster-only .`.

Этот граф создан в режиме `--code-only` без внешнего ключа LLM. Он охватывает Python и JavaScript; Markdown, HTML, CSS и `start.bat` Graphify этой версии в граф не включил. Файлы доступны напрямую, а при появлении поддерживаемого LLM-бэкенда можно перестроить полный граф.

Изменения сохраняются осмысленными Git-коммитами после проверенных этапов. Локальная база и `.venv` исключены из репозитория.

## Ограничения

Приложение предназначено для локального запуска. Авторизация и сложные роли не реализованы. Для общедоступного сервера потребуется добавить защиту доступа и настроить развёртывание.
